# Matcap Generator

A browser-based tool for creating and customizing matcap (material capture) textures.

## Features

- Real-time WebGL sphere and 3D mesh preview
- Custom lighting controls (position, color, intensity, size, softness)
- Material property adjustments (roughness, metallic, clear coat, rim light, edge darkening)
- Built-in material presets and random generation
- PNG export with resolution options from 512px to 4K

## Usage

Open index.html in a web browser or visit the GitHub Pages site.
